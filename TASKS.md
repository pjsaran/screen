## Found before the area reviews reported (to verify and fix)

- [ ] `build/installer/version.iss` is tracked but regenerated by every build, so every build dirties the tree
- [ ] 14 integration tests carry no category and are excluded by the build/CI filter (GraphUploader, CredentialVault, MessageOnlyWindow)
- [ ] Installer ships PDBs and XML doc files from `publish/`
- [ ] Elevated setup executes `captr.exe` from an install path read from HKCU first
- [ ] Setup's `taskkill /F /IM Captr.App.exe` kills every user's recording host, not just the installer's user
- [ ] `/WORKINGFOLDER="D:\x\"` (trailing backslash) breaks the quoted argument to `captr settings init`
- [ ] `sign.ps1` passes the PFX password on signtool's command line; signs only 4 files; uninstaller never signed
- [ ] Signing env var names disagree between `sign.ps1`, `releasing.md`, `new-release.ps1`, `release-verification.md`
- [ ] Docs claim an LGPL FFmpeg build (`building.md`, `release-verification.md`) while the lock pins GPL
- [ ] `design-decisions.md` holds two contradictory tray-icon entries (does not animate / blinks)
